# SPARC — Scheduling Platform with AI-Driven Resource Coordination

A website to book appointments online with an included AI assistant.

---

## 📌 Overview

SPARC is a scheduling and appointment booking platform that combines a standard booking workflow with an AI-driven assistant to help coordinate resources — reducing manual back-and-forth in scheduling appointments and managing availability.

## 🧠 Key Features

🔹 Online appointment booking
🔹 AI assistant for scheduling help
🔹 Resource/availability coordination
🔹 Clean, simple booking interface

## ⚙️ Technologies Used

- HTML, CSS, JavaScript 🌐
- AI/LLM integration for the assistant

## 🚀 Getting Started

### Installation
```bash
git clone 
cd sparc-scheduling-platform
```
Open `index.html` in your browser, or serve the folder with a local server if it needs one.
